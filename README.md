# Sinners 2 Saints website

Files
- index.html: main landing page
- community.html: free community page
- 404.html: shown when a page isn't found
- .nojekyll: tells GitHub Pages to serve the files as-is

## Edit your content
Open index.html or community.html in a text editor. Find the block marked
"EDIT THIS BLOCK" and paste your links between the quotes. A blank link shows as "coming soon".

## Publish on GitHub Pages
1. Create a free account at github.com and click New repository.
2. Name it (for example "sinners2saints"), set it to Public, and create it.
3. Click "uploading an existing file", drag in ALL files from this folder
   (including 404.html and .nojekyll), and click Commit changes.
4. Go to Settings > Pages. Under Build and deployment, set Source to
   "Deploy from a branch", Branch to "main" and folder to "/ (root)". Save.
5. After a minute or two your site is live at
   https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

Tip: if you name the repository YOUR-USERNAME.github.io, the site lives at
https://YOUR-USERNAME.github.io/ and the 404 page's home link works as-is.

## Use your own domain (optional, about $10 a year)
1. Buy the domain (for example sinners2saints.com) from any registrar.
2. In Settings > Pages, type the domain under Custom domain and save.
3. At your registrar, add the DNS records GitHub shows you (see GitHub's
   "Managing a custom domain for your GitHub Pages site" help page).
4. Tick "Enforce HTTPS" once it becomes available.

## Updating later
Edit the file on your computer, then upload it again to the repository (or click
the file on GitHub, then the pencil icon to edit it online). Changes go live in a minute or two.
